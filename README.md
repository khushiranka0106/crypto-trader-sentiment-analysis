# Crypto Trader Behavior Analysis Using Market Sentiment

## Project Overview

This project analyzes historical cryptocurrency trading data together with the Fear & Greed Index to understand how market sentiment influences trader behavior and profitability.

The analysis combines trading records with daily market sentiment to evaluate trader performance under different market conditions.

---

## Objectives

- Clean and preprocess trading data
- Merge trading data with Fear & Greed Index
- Analyze trader performance across market sentiment
- Segment traders based on behavior
- Generate actionable insights

---

## Dataset

### Historical Trader Data

Contains:

- Account
- Coin
- Execution Price
- Size USD
- Closed PnL
- Direction
- Timestamp

### Fear & Greed Index

Contains:

- Date
- Sentiment Classification
- Sentiment Value

---

## Key Insights

- Extreme Greed recorded the highest average profitability and win rate.
- Fear market conditions showed the highest trading activity.
- Large position traders achieved higher average profits than small position traders.
- Trading behavior changes significantly with market sentiment.
